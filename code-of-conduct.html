Safety // Excellence // Respect

CODE OF
CONDUCT.

Scope: Forums, Wiki, Repositories, IRC, Private Correspondence, and Public Meetings.

Ensure excellence in
every interaction.

The purpose of our Code of Conduct is to ensure all participants have the best possible experience. Diversity is our strength, but it requires ground rules to ensure we remain an excellent space for collaboration.

"Take it in the spirit in which it's intended — a guide to make it easier to be excellent to one another. Follow it in spirit as much as in the letter."

Expected Behavior

EMPATHY // 01

Be Considerate

Your work affects users and colleagues. Take consequences into account when making decisions.

GROWTH // 02

Be Patient

Patience helps build empathy towards others within the learning environment.

SAFETY // 03

Be Respectful

Respect helps us feel safe and empowered to express our ideas freely.

KINDNESS // 04

Be Nice

Treat others as you would like to be treated in your quest for knowledge.

CLARITY // 05

Communicate

Effective communication fosters good working relationships with all peers.

SUPPORT // 06

Ask for Help

Don't be afraid to ask for help when unsure; we learn together.

Unacceptable Behavior

01

Violent threats directed against another person.

02

Discriminatory jokes and harmful language.

03

Posting or threatening to post personally identifiable information (Doxing).

04

Personal insults and targeted harassment.

05

Unwelcome sexual attention in any form.
